# Работа с ЭЛО

Это самостоятельная статическая браузерная игра на русском языке. Сначала прочитайте README.md.

## Запуск и проверка
- Запуск: python3 -m http.server 3000 --directory dist
- Проверка: node --check dist/app.js
- Зависимостей и шага сборки нет; dist содержит исходники, его нужно отслеживать в Git.
- Для изменений поведения проверьте полный сценарий: запрос → кубик → практика/пропуск → шесть ходов → действие → дневник/экспорт. Проверьте досрочное завершение и перезагрузку страницы.
- Если доступен браузер, проверьте мобильную и настольную версии. Сообщайте, какие проверки фактически выполнены.

## Продукт
- Сохраняйте русскоязычный интерфейс, спокойную шалфейную палитру и выразительные serif-заголовки.
- Игра — самонаблюдение, без рейтинга духовного развития и без предсказаний. 24 авторских состояния не выдавать за традиционную доску «Лилы».
- Не утверждайте научную или лечебную эффективность без доказательств.
- Не добавляйте backend, платные API или AI без задачи пользователя.
- Записи личного дневника не отправляются на сервер. Сохраняйте экранирование пользовательского текста и подтверждение перед удалением записей.
- При изменении структуры сохранений предусмотрите совместимость или миграцию localStorage.
