# ЭЛО — эволюция личной осознанности

Рабочий авторский прототип браузерной игры для самонаблюдения, вдохновлённой идеей путешествия по состояниям из «Лилы». Эффективность игры научно не проверена.

## Запуск

Не нужны npm install, API-ключи или сборка. Нужен Python 3 для локального сервера:

```sh
python3 -m http.server 3000 --directory dist
```

Открыть http://localhost:3000. Проверка синтаксиса JavaScript (Node.js):

```sh
node --check dist/app.js
```

## Структура

- dist/index.html — разметка, адаптивные стили и игровое поле SVG.
- dist/app.js — 24 состояния, вопросы, практики, кубик, шесть ходов, таймер, дневник, экспорт.
- .openai/hosting.json — идентификатор исходного проекта Sites; сохранять при продолжении работы над этим же сайтом.

Прогресс хранится в localStorage браузера (elo-journey-v1). Серверного хранения и AI нет. Записи не переносятся между устройствами или доменами; для переноса используйте экспорт дневника.

## Продолжение в Codex

Выберите репозиторий meditationpochta/elo и ветку main при создании окружения Codex. Устанавливать зависимости не требуется. Попросите Codex прочитать AGENTS.md и README.md, запустить игру, проверить её в браузере, затем внести нужные изменения.

## Проверка

Проверены синтаксис и сценарий шести ходов в программном тесте с упрощённым DOM. Визуальная проверка в настоящем браузере ещё не выполнена. Проверьте мобильный экран, таймер, пропуск хода, досрочное завершение, восстановление после перезагрузки, дневник и скачивание.
